# Nextcloud MCP Server

[English](README.md) · **Русский**

MCP-сервер для любого инстанса Nextcloud. Файлы, поиск, загрузка и скачивание (файлов и целых папок), общий доступ и публичные ссылки, избранное, корзина. Работает с любым MCP-клиентом (Claude Code, Claude Desktop, Cursor и т. д.).

Только официальные API: WebDAV (`/remote.php/dav`) и OCS (`files_sharing`). Нужен **Node.js ≥ 20.12**.

## Инструменты (23)

| Инструмент | Что делает |
|---|---|
| `login` | Вход через браузер (Login Flow v2, SSO работает); пароль приложения сохраняется |
| `disk_info` | Занято / доступно |
| `list_files` | Содержимое папки (сортировка, `limit`/`offset`) |
| `get_file_info` | Метаданные: размер, даты, MIME, ID файла, права, ссылка в веб |
| `search_files` | Поиск на сервере по имени (подстрока, без учёта регистра) по дереву папки, фильтр MIME |
| `recent_files` | Файлы, изменённые за последние N дней |
| `create_folder` | Создать папку (вместе с родительскими) |
| `copy` / `move` | Копировать / переместить, переименовать |
| `delete` | Удалить (несколько путей за вызов; в корзину) |
| `upload_file` | Загрузить локальный файл (файлы > 10 МБ — по частям) |
| `upload_folder` | Загрузить локальную папку рекурсивно, параллельно |
| `download` | Скачать файл или целую папку на этот компьютер |
| `read_file` | Прочитать текстовый файл (первые 200 КБ) |
| `set_favorite` | Добавить / убрать из избранного |
| `create_share` | Публичная ссылка (пароль, срок, метка) или доступ пользователю / группе / по email |
| `list_shares` | Мои расшаривания (все, одного пути; с `subfiles` — всё внутри папки на любой глубине) |
| `list_shared_with_me` | Что расшарили мне |
| `update_share` / `delete_share` | Изменить / убрать доступ |
| `list_trash` / `restore_from_trash` / `clear_trash` | Корзина |

Пути — от корня ваших файлов: `/`, `/Projects/logo.svg`. Ссылка из приложения «Файлы» тоже подходит как путь: `https://cloud.example.com/apps/files/files/123?dir=/Projects/`.

## Установка

```bash
git clone https://github.com/a-lagutov/nextcloud-mcp.git
cd nextcloud-mcp
npm install
npm run build
```

Claude Code:

```bash
claude mcp add nextcloud -s user -- node /absolute/path/to/nextcloud-mcp/dist/index.js
```

Claude Desktop (`claude_desktop_config.json`):

```json
{
  "mcpServers": {
    "nextcloud": { "command": "node", "args": ["/absolute/path/to/nextcloud-mcp/dist/index.js"] }
  }
}
```

## Вход

Сервер запускается без настройки. Попросите Claude «войди в Nextcloud https://cloud.example.com» или выполните `npm run login -- --server https://cloud.example.com`. Адрес сервера запоминается, при следующих входах `server_url` не нужен:

1. В браузере по умолчанию откроется страница входа сервера — войдите как обычно (SSO тоже) и нажмите «Разрешить доступ».
2. Nextcloud выдаст **пароль приложения** для этого сервера; он сохранится в `~/.config/nextcloud-mcp/credentials.json` (права 600) и сразу заработает, без перезапуска.

Инструмент `login` ждёт до 2 минут, затем возвращает ссылку входа и завершает вход в фоне (ссылка действует 20 минут). Чтобы перейти на другой сервер, передайте новый `server_url` / `--server`.

Без браузера (Docker, SSH): создайте пароль приложения в Nextcloud → Настройки → Безопасность → «Создать пароль приложения» и передайте `login_name` + `app_password` в `login` или `npm run login -- --user <ЛОГИН> --password <ПАРОЛЬ_ПРИЛОЖЕНИЯ>`.

> ⚠️ Пароль приложения даёт полный доступ к вашим файлам. Отозвать его можно в любой момент: Настройки → Безопасность → Устройства и сеансы (он называется `nextcloud-mcp (<хост>)`).

### Переменные окружения (необязательно)

Перекрывают сохранённые значения — например, в Docker/CI.

| Переменная | Назначение |
|---|---|
| `NEXTCLOUD_URL` | URL сервера, например `https://cloud.example.com` |
| `NEXTCLOUD_USER` | Логин |
| `NEXTCLOUD_APP_PASSWORD` | Пароль приложения |
| `NEXTCLOUD_USER_ID` | Внутренний ID пользователя, если отличается от логина (иначе один раз вызовите `login`) |

## Ограничения

- `search_files` ищет только по именам, не по содержимому; не больше 500 результатов за вызов.
- `list_files` получает всю папку одним PROPFIND и листает локально, поэтому огромные папки открываются не мгновенно.
- Удаление из папки, расшаренной вам, кладёт элемент в корзину владельца, а не в вашу.
